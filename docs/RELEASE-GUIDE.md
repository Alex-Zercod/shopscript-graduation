# Подготовка выпускного проекта

## Готово локально

Приложение 2026-11-18.1, актуальные README и инструкция, скилл, учебное задание без личных данных и 21 локальная проверка. `python scripts/build_release.py` создаёт проверяемый архив по явному списку файлов. Он не публикует проект.

## До сдачи

1. Проверить полный путь на учебном задании: ввод, генерация, выбор, разворачивание, экспорт. Модельные pass не доказывают готовность всех сценариев.
2. Скриншоты учебного прогона 20 ноября добавлены в images/, README и явный список сборщика. Перед записью при необходимости обновить кадры. Сохранён экспорт examples/demo-result.json.
3. Опубликовать чистый проект на GitHub, включая `.claude/skills/shopscript-maintenance/SKILL.md`, и проверить доступ к репозиторию без авторизации. Публичный репозиторий: https://github.com/Alex-Zercod/shopscript-graduation .
4. Записать демонстрацию на 3–5 минут. При долгом запросе показывать заранее сохранённый реальный результат с указанием его происхождения.
5. Вставить ссылку на репозиторий в задание курса и отдельную ссылку на скилл в анкету. Согласие на публикацию и отзыв выбирает сам автор проекта.

## Статус пилота

Первые сценарии клиент отверг. По его замечаниям изменена схема: хук, боль, решение, покупка по прикреплённой ссылке. Последние дерзкие формулировки написаны и отредактированы вручную, понравились автору проекта; одобрение клиента и данные публикации ещё ожидаются. Не называйте этот этап завершённым пользовательским тестом и не утверждайте, что автоматическая генерация стабильно повторяет ручной результат.

## В публикацию не включать

Ответы и фото клиента, пользовательские экспорты, историю переписки, внутренние разборы, логи, `.env`, ключи и файлы аккаунта Ollama. Сборщик использует явный список. Нельзя загружать всю рабочую папку или всю docs/ без проверки. Статический лендинг не запускает Python-сервер.
